# NguyenWare prototypes

Three casual game prototypes for playtesting through the NguyenWare playtest hub:

| Game | Id | What it is |
|---|---|---|
| Echo | `echo` | Haunted house where the same evening repeats; your past nights replay as echoes |
| Lasso | `lasso` | Sheepdog herding; rope one color of sheep at a time, played in short days |
| Fuse | `fuse` | Turn tiles ahead of a burning fuse; endless |

Each game is a static-assets-only Cloudflare Worker named after its id, deployed from its own folder.

## Layout
- `src/`: the source. `core-top.js` and `core-shell.js` are shared; `<id>.js` is each game; `page.html` and `style.css` are the page.
- `manifests/<id>.json`: the hub manifest (`playtest.json`) for each game. Update `build`, `what_to_test` and `known_issues` every time a build goes to testers.
- `shared/fonts/`: self-hosted Unbounded and Figtree (SIL Open Font License, files included).
- `<id>/public/`: generated by `npm run build`, committed, and served by `<id>/wrangler.jsonc`. Don't edit by hand; `media/` holds the promo images.
- `tools/build.mjs`: writes `<id>/public` and `<id>/wrangler.jsonc`.

## Deploy
Workers Builds, one Worker per game on the same repo: root directory `/echo`, `/lasso` or `/fuse`, deploy command `npx wrangler deploy`, build watch path `<id>/*`. Run `npm run build` and commit before pushing.
